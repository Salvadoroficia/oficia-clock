El acceso y uso del Servicio implica la aceptación expresa y sin reservas de todos los términos del presente Aviso Legal. Si el usuario no está de acuerdo con estos términos, deberá abstenerse de utilizar el Servicio.

3.1. Uso Autorizado

El Servicio está destinado exclusivamente a:

  • Empleados de Oficia Sistemas SL

El acceso no autorizado al Servicio está prohibido y puede constituir un delito.

3.2. Obligaciones del Usuario

El usuario se compromete a:

  • Hacer un uso correcto y lícito del Servicio
  • Mantener la confidencialidad de sus credenciales de acceso
  • Notificar inmediatamente cualquier uso no autorizado de su cuenta
  • No manipular, alterar o falsificar registros de fichaje
  • No realizar acciones que puedan dañar, inutilizar o sobrecargar el Servicio
  • No utilizar el Servicio para fines distintos al control de jornada laboral

3.3. Usos Prohibidos

Queda expresamente prohibido:

  • Ceder o transferir credenciales de acceso a terceros
  • Realizar "fichajes" por cuenta de otros empleados
  • Manipular o falsificar datos de geolocalización
  • Intentar acceder a áreas restringidas del sistema
  • Realizar ingeniería inversa, descompilar o extraer el código fuente
  • Utilizar el Servicio para transmitir malware o código malicioso
